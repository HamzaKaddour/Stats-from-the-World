Engineering & methodology

This site is the deployment layer of an end-to-end analytics project, not a screenshot or mock dashboard.

1 · Ingestion & ETL

Python requests World Bank indicator and country metadata, removes aggregate entities, joins metrics by country-year, validates numeric fields and writes a columnar Parquet dataset.

2 · Browser analytics

GitHub Pages loads the processed Parquet artifact directly. Filtering, aggregation, rankings and chart preparation run client-side, so no application server is required.

3 · Interpretation

Values are reported observations and coverage varies by country and year. Rankings are descriptive only. No custom score on this page is presented as an official World Bank index.
