Data engineering, trust & reproducibility

The platform is designed as a small public-data product: automated ingestion, country harmonization, metric-level provenance, validation, columnar storage and a zero-backend deployment architecture.

01 · INGESTION

Authoritative multi-source data

World Bank WDI supplies reported development observations. IMF World Economic Outlook / DataMapper fills selected current and future macroeconomic series with clearly marked estimates or projections.

02 · HARMONIZATION

ISO country model + provenance

Country records are harmonized through ISO identifiers. Every analytical metric carries its own source and status so mixed-source country-year rows never obscure where a displayed number came from.

03 · DELIVERY

Serverless analytical architecture

GitHub Actions refreshes and validates the data, Parquet provides a compact analytical layer, and GitHub Pages performs filtering and visualization client-side without a paid database or application server.
