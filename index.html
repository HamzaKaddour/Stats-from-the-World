Data pipeline

World Bank WDI → API ingestion → country metadata filtering → country-year analytical dataset → interactive browser visualization. The repository also contains a Python/Pandas ETL pipeline and a Streamlit analytics implementation.

Data notes

Coverage differs by indicator, country, and year. The latest reported observation may therefore differ across metrics. Rankings reflect available observations only and should not be interpreted as policy or welfare rankings.
